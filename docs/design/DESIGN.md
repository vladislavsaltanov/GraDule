# GraDule — Design System

Источник: три HTML-прототипа из claude.ai design (см. `home-schedule.html`, `grades.html`,
`grade-changes.html`). Это **единственный источник истины** по цветам и геометрии.
Дизайн — «карточка-папка»: тёмная подложка + светлый лист бумаги + цветная кромка справа.

Холст прототипа: 1152×2560 px. Телефон = 384 dp ⇒ **dp = px / 3** (все числа ниже уже в dp).

## Токены

| Токен | HEX | Где |
|---|---|---|
| `card` | `#3A3937` | подложка карточки, чипы шапки, дно навбара, экран настроек |
| `paper` | `#C0C0C0` | лист внутри карточки, «рельс» под иконками навбара |
| `bg` | `#E8E8E8` | фон экрана, текст поверх тёмного |
| `ink` | `#1A1A1A` | текст на бумаге (заголовок, аудитория, оценка) |
| `practice` | `#EE7747` | кромка + акцент «практика» |
| `lecture` | `#559A8A` | кромка + акцент «лекция» (дефолт) |
| `white` | `#FFFFFF` | текст на тёмном (дата, время, навбар) |
| `black` | `#000000` | статус-бар/верхняя чёрная полоса |

Радиусы: карточка 9 dp (28 px), клип карточки 7 dp (20 px), лист 6 dp (18 px),
навбар 11 dp (32 px), аватары 17–33 dp.

Тени: карточка `0 4px 10px 3px rgba(0,0,0,.25)`; навбар `0 4px 4px 1px rgba(0,0,0,.25)`.

Шрифты: `Cascadia Code` (текст/время) и `Cascadia Mono` (крупные заголовки/цифры),
`Inter` — запасной. В приложении шрифты **не бандлятся**: `FontFamily.Monospace`
(см. `ui/theme/Type.kt`), иначе +1.5 МБ в APK. <!-- AGENT NOTE: не подтверждено,
что Cascadia выглядит приемлемо на Android; проверить на устройстве -->

## Геометрия

- Верхняя чёрная полоса (статус-бар приложения) 1152×107 px → 384×36 dp.
- Шапка: `y = 157` (52 dp), высота 100 px (33 dp), поля 26 px (9 dp):
  аватар 100 px (33 dp, круг), отступ 32 px, чип даты 836×100 px (279×33 dp, r=9 dp)
  с текстом по центру и иконкой справа 60 px (20 dp).
- Контент: `y = 307` (102 dp), боковые поля 16 px (5 dp), вертикальный шаг карточек 15 dp.
- Нижний навбар: 814×188 px → 271×63 dp, r=11 dp, `y = 2281` (760 dp), по центру,
  подпись 9 sp сверху, «рельс» `paper` 814×130 px (271×43 dp) с тёмной подложкой
  200×116 px (67×39 dp) под активной иконкой. Иконки 16 dp, 4 слота.

## Компоненты

### Пара (lesson card) — главная, 373×107 dp
1. Клип `r=7dp`, внутри подложка `card` r=9dp 373×100 dp + тень.
2. Лист `paper` r=6dp, `x=7dp y=20dp`, 360×75 dp, правая кромка 6 dp цветом типа.
3. Время — 11 sp `bg`, `x=20dp y=8dp` (над подложкой, на тёмном).
4. Заголовок — 18 sp 700, `x=18dp y=27dp`, до 2 строк.
5. Преподаватель — 9 sp, 65 %, `y=71dp`; ниже «ауд. 317 • практика» 11 sp 600.

### Оценка (grade card) — экран оценок, 373×73 dp
1. Клип r=7dp, подложка `card` r=9dp 373×63 dp + тень.
2. Лист `paper` r=6dp `x=7dp y=4dp` 293×55 dp, кромка 6 dp (`lecture`/`practice`).
3. Название дисциплины 18 sp 600 `ink`; справа крупная цифра оценки 18 sp 700 `bg`.

### История изменений (change card) — 373×108 dp
Три слоя: подложка `card` (верх 81 dp) → лист `paper` → футер 23 dp на `card`.
Сверху дата слева и время справа (11 sp `bg`); заголовок пары 18 sp 700;
строка контекста 11 sp 400; футер: метка «изменение»/`посещено`/`пропущено`
11 sp 700 `ink` слева, значение справа, иконка-фото 20 dp по центру.

### Пустой/ошибка
Не «тихо»: `SyncUiState` (см. `ui/SyncUiState.kt`) — Loading, Empty(нет данных /
факультет не поддержан), Content, StaleWithError, FailedNoCache.

## Отклонения от прототипа (осознанные)

- Иконки: кастомные SVG прототипа заменены на `material-icons-core`
  (Home / DateRange / Star) — 0 новых зависимостей.
- Цвета фиксированы брендом, **динамические цвета Android 12+ выключены по умолчанию**
  (дизайн брендовый), но поддержка есть флагом `dynamicColor` в `GraDuleTheme`.
- Тёмная тема в прототипах отсутствует — выведена инверсией: bg `#1A1A1A`,
  card `#2A2927`, paper `#3A3937`, ink `#E8E8E8`. <!-- AGENT NOTE: подтвердить с
  владельцем дизайна -->
