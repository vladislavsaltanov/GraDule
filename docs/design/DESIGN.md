# GraDule — Design System

Источник истины — Figma-файл MMCS-GraDule: `ScheduleScreenNew` 76:187 и
`GradesScreen` 81:112 (LessonCard 76:208 и 81:133). Дизайн — «карточка-папка»:
тёмная подложка + светлый лист бумаги + цветная кромка справа.

Холст 1152×2560 px. Телефон = 384 dp ⇒ **dp = px / 3** (все числа ниже уже в dp).

Радиусы: подложка 10.67 dp (32 px), лист 8 dp (24 px), клип фрейма карточки
6.67 dp (20 px), док 10.67 dp (32 px), круг шапки 16.67 dp (50 px).

Тени: карточка `0 4px 10px 3px rgba(0,0,0,.25)`; док `0 4px 4px 1px rgba(0,0,0,.25)`.

Шрифты забандлены, `ui/theme/Type.kt`: Cascadia Mono (OFL, Microsoft) —
заголовок и текст на бумаге, Cascadia Code (OFL, Microsoft) — дата, оценка,
подписи дока, IBM Plex Mono (OFL, IBM, `res/font/ibm_plex_mono_semibold.otf`) —
время пары. Тексты лицензий: `docs/licenses/OFL-Cascadia.txt`,
`docs/licenses/OFL-IBM-Plex-Mono.txt`.

## Геометрия экрана (общая для обеих нод)

- В Figma чёрная полоса сверху: 1152×107 px → 384×35.67 dp. В Android зона status bar прозрачна над фоном экрана.
- Шапка: `y = 157` (52.33 dp), высота 100 px (33.33 dp), поля по краям 26 px
  (8.67 dp), промежутки 32 px (10.67 dp): круг-меню 100 px (33.33 dp), чип даты
  836×100 px (278.67×33.33 dp, r 9.33) с текстом 16 sp по центру и иконкой
  20 dp в 20 dp от правого края, круг-аватар 100 px.
- Отступ шапки: 12 dp от системного статус-бара сверху и 16.67 dp снизу. Figma-значение 50 px (16.67 dp) сверху — для кадра без высокого inset; на устройствах он компенсируется.
- Контент: боковые поля 16 px (5.33 dp).
- Док: 814×188 px (271.33×62.67 dp), r 32 px, по центру, `y = 2281` (760.33 dp).
  Подпись 28 px Code с отступом 10 px сверху, рельс `paper` 814×130 px
  (43.33 dp), тёмный слот активной вкладки 200×116 px (66.67×38.67 dp, r 9.33),
  иконки 53 px (17.67 dp) с шагом 200 px (66.67 dp). Активная иконка белая,
  неактивные чёрные. Отступ снизу до системной полосы 16.67 dp.
- Чёрная полоса снизу (2519..2560 px) и белый «home indicator» — это системные
  элементы Android, приложение их не рисует.

## Компоненты

### Пара (LessonCard 76:208, новый стиль) — фрейм 1120×320 px, шаг 335 px

1. Фрейм прозрачный 373.33×106.67 dp, r 20 px, обрезка по фрейму; подложка
   `card` 1100×300 px (100 dp, r 32 px) с полями фрейма 10 px (3.33 dp) по
   бокам и 20 px (6.67 dp) снизу; тень `0 4/10/3 25 %`. Зазор 15 px (5 dp).
2. Лист `paper` 1070×215 px (356.67×71.67 dp, r 24 px) на 70 px (23.33 dp) от
   верха подложки, поля 15 px (5 dp) по бокам; кромка — правый бордер 24 px
   (8 dp) радиусом 24 px, цвет типа: практика `#EE7747`, лекция и дефолт
   `#559A8A`. Внизу под подложкой 15 px (5 dp).
3. Время — IBM Plex Mono 30 px (10 sp) 600 `bg`, по центру ячейки; бокс 25 px
   на 23 px от подложки, сдвиг 5.17 dp компенсирует базовую линию Compose.
4. Заголовок — Cascadia Mono 700 `ink`, бокс 1003 px, отступ 20 px (6.67 dp) от
   верха листа и 35 px (11.67 dp) от левого. Размер выбирает `TextMeasurer`:
   помещается в одну строку — 72 px / 25 sp, иначе 60 px / 21 sp (плотнее, чем
   макетные 52 px) и до двух строк. Две строки занимают 126 px из 215 px листа.
5. «ауд. 120 • лекция» — Cascadia Mono 32 px (10.67 sp) 600 `ink` 65 %, бокс
   1030 px, прижата к низу листа (20 px), разделитель `•` — 400. Заметка
   сервера («с 17-00 до 18-30») дописывается в эту же строку.

Строки разведены `Spacer(weight = 1f)`: заголовок сверху, «ауд. • тип» снизу,
пустого провала между ними не появляется. Преподавателя в этом стиле нет.

### Оценка (LessonCard 81:133) — фрейм 1120×220 px, шаг 220 px (зазора нет)

1. Подложка `card` 1100×190 px (63.33 dp, r 9.33) + тень; 30 px (10 dp) снизу.
2. Лист `paper` 880×166 px (293.33×55.33 dp, r 6) на 12 px (4 dp) сверху и
   10 px (3.33 dp) слева; кромка 6 dp цветом типа.
3. Дисциплина — 18.33 sp 600 `ink`, до 2 строк, бокс (30, 24) px от листа.
4. Оценка — 18.33 sp 700 Code `bg`, правый край подложки минус 30 px (10 dp),
   верх 23 px (7.67 dp).

### Пустой/ошибка
Не «тихо»: `SyncUiState` (см. `ui/SyncUiState.kt`) — Loading, Empty(нет данных /
факультет не поддержан), Content, StaleWithError, FailedNoCache. Карточка
состояния — та же подложка 63.33 dp с листом.

## Отклонения от дизайна (осознанные)

- Подгрупп в UI нет: подгруппа выбирается в профиле, экран показывает всё.
- Иконки дока: календарь взят из Figma (Vector 133:938 → `res/drawable/
  ic_dock_schedule.xml`); остальные пока `material-icons-core` — 0 зависимостей.
  Звезда (Vector 133:933) и иконки слотов 3–4 ждут снятия лимита Figma API.
- Цвета фиксированы брендом, **динамические цвета Android 12+ выключены по
  умолчанию**, поддержка есть флагом `dynamicColor` в `GraDuleTheme`.
- На Android под статус-баром продолжается `bg`, системные значки тёмные (в Figma frame там чёрная полоса).
- Тёмная тема в прототипах отсутствует — выведена инверсией: bg `#1A1A1A`,
  card `#2A2927`, paper `#3A3937`, ink `#E8E8E8`. <!-- AGENT NOTE: подтвердить с
  владельцем дизайна -->
