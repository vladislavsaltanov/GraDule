# Story e05s02: Экспорт/импорт в UI

**type:** feat
**risk:** P1
**context:** domain
**Context:** Клиентская половина обмена:
экспорт текущего расписания на сервер,
импорт по ссылке одним тапом. Импорт —
локальный снапшот без связи с оригиналом:
обновления не подтягиваются, диалог честно
предупреждает. Зависит от e05s01.

## Requirements

#### ADDED: Экспорт и импорт
Отправка JSON, приём ссылки, импорт в LOCAL.

#### ADDED: Снапшот-варнинг
Текст «снимок, не обновляется» в диалоге.

## Steps

1. Экспорт/импорт + варнинг
→ verify: `./gradlew :app:testDebugUnitTest`
2. Сквозной прогон на чистом устройстве
→ verify: `./gradlew :app:assembleDebug`

## Verification Script

1. Экспорт → ссылка → импорт на чистом:
пары, времена, подгруппы совпали.
2. Диалог показывает предупреждение.

## Out of scope

- Сервер (e05s01), PDF (e07s02).

## Risks

- Импорт чужого семестра → метка семестра
видна до подтверждения.
