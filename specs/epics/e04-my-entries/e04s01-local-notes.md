# Story e04s01: LOCAL-записи, заметки, архив

**type:** feat
**risk:** P0
**context:** domain
**Context:** Пользовательский слой поверх
серверного шаблона: повторяющиеся (с чётностью)
и разовые записи, скрытия серверных, заметки
и напоминания на вхождение (запись+дата),
экран напоминаний. Scope по семестрам:
старое смотрибельно архивом, новый чистый,
переноса нет. LOCAL не участвует в серверном
синке и переживает его.

## Requirements

#### ADDED: Свои записи и скрытия
WEEKLY (FULL|UPPER|LOWER) + ONE_OFF;
скрытие серверной пары; всё переживает синк.

#### ADDED: Заметки на вхождение
Текст + напоминание привязаны к дате;
у разовых — к записи; экран напоминаний.

#### ADDED: Архив по семестрам
Переключение семестров-шаблонов; новый
семестр стартует чистым.

## Steps

1. LOCAL + скрытия + архив-scope
→ verify: `./gradlew :app:testDebugUnitTest`
2. Заметки на вхождение + напоминания
→ verify: `./gradlew :app:testDebugUnitTest`

## Verification Script

1. Создать запись, прогнать синк — на месте.
2. Заметка «контрольная 14.10» — только на дате.
3. Сменить семестр — архив виден, новый чист.

## Out of scope

- Оверрайды серверных (e04s02), обмен (e05).
- Точные алармы: разрешение уточняется
при реализации (A5-грилл).

## Risks

- Заметка на шаблон вместо вхождения —
регресс-тест на две даты.
