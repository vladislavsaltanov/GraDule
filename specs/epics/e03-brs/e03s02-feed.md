# Story e03s02: Лента событий

**type:** feat
**risk:** P1
**context:** domain
**Context:** Отдельный экран ленты: сортировка
по дате, без агрегации; типы (выставлены /
изменены / удалены / посещение); изменение
балла сервер пишет двумя событиями. Ждёт
e00s01 (R1: Content-Type и структура).
Дискавери-деталь: формат не подтверждён,
Gson-`List<BrsEventDto>` под вопросом —
конвертер выбирать по фикстуре.

## Requirements

#### ADDED: Парсер ленты по фикстуре R1
Поля события — только подтверждённые
фикстурой (id/timestamp/disciplineId —
если есть).

#### ADDED: Экран ленты
Сортировка по дате, без агрегации баллов.

## Steps

1. Парсер + тесты на events.raw
→ verify: `./gradlew :app:testDebugUnitTest`
2. Экран ленты офлайн из кэша
→ verify: `./gradlew :app:assembleDebug`

## Verification Script

1. События «удалены» не вычитаются из Rate.
2. Авиарежим — лента из кэша.

## Out of scope

- Уведомления (e06), инкрементальный синк
по ленте (только после стабильности формата).

## Risks

- Формат XML → брать XML-конвертер/ручной
парсер, не Gson.
- Поля без id → дедуп по содержимому+дате.
