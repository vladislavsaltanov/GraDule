# Story e02s02: Выбор группы + экран дня

**type:** feat
**risk:** P0
**context:** domain
**Context:** Адаптеры вокруг ядра e02s01:
выбор группы (уровень → курс → направление →
номер) с резолвом id по human-ключу (B5:
числовой id — кэш, не идентичность),
загрузка шаблона, экран дня (свайп, подсветка
сегодня, info, фильтр подгруппы), состояния
пусто/не-поддержано. Zoom-out: модуль ядра
e02s01 — назначение: шаблон→даты; вызывающий —
этот срез; контракт: сигнатуры парсера
и entries-on-date не менять.

## Requirements

#### ADDED: Резолв группы по human-ключу
Хранить (уровень, курс, направление, номер);
при пустом ответе/пропаже id — переопределить,
иначе попросить выбрать заново.

#### ADDED: Экран дня
Офлайн из Room; текущая/выбранная дата;
подгруппы без дублей в слоте; `info` видно.

## Steps

1. Group-resolve + загрузка + замена SERVER
→ verify: `./gradlew :app:testDebugUnitTest`
2. Экран дня + подгруппы + состояния
→ verify: `./gradlew :app:assembleDebug`

## Verification Script

1. Выбрать ФИИТ-2-4 — расписание совпадает
с сайтом на текущую неделю.
2. Выключить сеть — экран из кэша с пометкой.
3. Подгрупповой слот — только своя пара.

## Out of scope

- Свои записи (e04), обмен (e05).

## Risks

- id групп сменились на лету → пере-резолв
по ключу при каждой загрузке.
