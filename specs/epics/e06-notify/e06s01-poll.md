# Story e06s01: WorkManager-опрос и уведомления

**type:** feat
**risk:** P0
**context:** domain
**Context:** Уведомления без FCM-сервера: опрос
на устройстве. `PeriodicWorkRequest` каждый час,
flex 15 мин, сеть обязательна, экспоненциальный
backoff, `KEEP` от дублей. Дискавери-деталь:
`MIN_PERIODIC_INTERVAL_MILLIS` /
`MIN_PERIODIC_FLEX_MILLIS` — флоры существуют
(ref), фактический запуск сдвигают Doze
и оптимизация батареи. Триггер — лента e03s02;
уведомление при изменении тестового балла,
без повторов. FCM — только при доказанной
нужде в мгновенности (out).

## Requirements

#### ADDED: Периодический опрос
Часовой воркер + дифф баллов/ленты;
дедуп уведомлений; тихая ошибка без затирания.

#### ADDED: Уведомление об изменении
Текст с предметом и дельтой; тап ведёт
в детали дисциплины.

## Steps

1. Воркер + дифф + дедуп, тесты логики
→ verify: `./gradlew :app:testDebugUnitTest`
2. Ручной прогон: изменить балл — пуш пришёл
один раз
→ verify: `./gradlew :app:assembleDebug`

## Verification Script

1. Тестовое изменение балла → одно уведомление.
2. Повторный прогон без изменений — тишина.
3. Ошибка сети — старые данные + пометка.

## Out of scope

- FCM-сервер, хранение чужих токенов.
- Точные алармы напоминаний (e04): отдельный
флоу разрешений.

## Risks

- Doze сдвигает опрос на часы — в UI честный
«обновлено в HH:MM».
- `async` в `doWork` без scope — структура
по доке WorkManager.
